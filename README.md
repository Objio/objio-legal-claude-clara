# OBJIO LEGAL · Claude para Clara

La forma de trabajar del despacho OBJIO LEGAL, lista para instalar en **Claude web** (claude.ai) de la Lic. Clara Alcántara.

## Clara: cómo se usa (2 minutos)

1. Abre **claude.ai** y empieza una conversación nueva.
2. Pega este mensaje:

   > Lee https://raw.githubusercontent.com/Objio/objio-legal-claude-clara/main/EMPIEZA_AQUI.md y sigue sus instrucciones.

3. Claude te irá guiando paso a paso para dejarlo instalado en tu cuenta: un Proyecto «OBJIO LEGAL» con las instrucciones del despacho, tus preferencias personales y las 8 skills.

Si Claude no puede abrir el enlace, abre tú `EMPIEZA_AQUI.md` aquí en GitHub, copia el contenido y pégalo en la conversación.

## Qué trae

| Pieza | Para qué sirve |
|---|---|
| `instrucciones/INSTRUCCIONES_PROYECTO.md` | La forma de trabajar completa: producto terminado, verificación en fuente primaria, correo recortado, formato de documentos, derecho dominicano |
| `instrucciones/PREFERENCIAS_PERFIL.md` | Versión corta que rige en todas tus conversaciones |
| `instrucciones/MEMORIA.md` | Datos estables del despacho para la memoria de Claude |
| `skills/` y `dist/` | 8 skills (en texto y en ZIP para subir) |

## Las 8 skills

| Skill | Cuándo se activa |
|---|---|
| `acto-alguacil` | «notificar», actos de alguacil, emplazamientos, intimaciones, puestas en mora |
| `kit-pre-audiencia` | preparar una comparecencia personal, un informativo o un interrogatorio |
| `analisis-caso` | caso nuevo, estrategia, opciones, BATNA, riesgos, plan de acción |
| `investigacion-juridica` | buscar normas y jurisprudencia dominicanas y verificar su vigencia |
| `correo-despacho` | contestar o preparar correos del despacho |
| `documentos-objio-legal` | escritos, informes, opiniones y contratos en Word y PDF con la marca |
| `redline-documentos-terceros` | revisar un contrato o documento ajeno con cambios en amarillo y comentarios |
| `verificacion-antes-de-enviar` | revisión adversarial de todo lo que sale a un cliente, tribunal o contraparte |

Este repositorio no contiene datos de clientes ni de expedientes. Los datos de cada asunto los aporta Clara en la conversación, y son secreto profesional.
